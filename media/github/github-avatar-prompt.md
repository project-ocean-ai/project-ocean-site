# Project Ocean — GitHub Avatar Prompt

## Goal

Create a premium, cinematic GitHub avatar for Project Ocean that feels elegant, advanced, emotionally intelligent, and technology-forward.

The image should work at very small GitHub profile sizes while still looking recognizable and premium.

---

## Image Prompt

Minimal luxury AI brand avatar for Project Ocean.

Dark navy-black background with subtle glowing ocean wave ribbons and soft atmospheric lighting.

A clean luminous abstract “O” symbol centered in the composition, inspired by flowing water, continuity, intelligence, and memory.

The symbol should feel futuristic but emotionally warm — not corporate, not robotic.

Use elegant blue-white glow accents with cinematic contrast.

Minimal composition.
No people.
No faces.
No text.
No clutter.
No watermark.

Style references:
Apple-level minimalism,
high-end AI branding,
cinematic depth,
luxury technology aesthetic.

Square composition (1:1).
Optimized for GitHub profile visibility at small sizes.
